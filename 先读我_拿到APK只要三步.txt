===============================================================
   天宫ERP系统 · 安卓版   怎样拿到 APK 装到手机
===============================================================

你只需要做 3 件事：建仓库 → 传文件 → 下载 APK。
全程在网页上点，不用装任何软件，不用敲任何命令。


────────────────────────────────────────────
 第 1 步：注册 / 登录 GitHub（免费）
────────────────────────────────────────────
浏览器打开 https://github.com

没有账号 → 点右上角 Sign up，用邮箱注册（免费）
已有账号 → 点 Sign in 登录


────────────────────────────────────────────
 第 2 步：新建一个仓库
────────────────────────────────────────────
登录后，点页面右上角的 “+” 号 → New repository

  Repository name 填：  tiangongerp
  下面选择：           Public（公开）
                       （选 Private 也行，但免费额度少一点）
  其他都不要动

拉到最下面，点绿色的 Create repository

注意：免费账户就够用，不需要买任何付费服务


────────────────────────────────────────────
 第 3 步：把本文件夹里的东西传上去
────────────────────────────────────────────
进到刚建好的仓库页面，会看到一句
   “…or create a new repository on the command line”
下面有一行链接： uploading an existing file
点它（或者点 Add file → Upload files）

然后把【本文件夹里的内容】全部拖进网页的虚线框：

   · 文件夹  app              ← 程序本体，必须传
   · 文件    buildozer.spec   ← 打包配置，必须传
   · 文件夹  .github          ← 构建脚本（拖不上去就看下面的备用办法）

拖进去后拉到最下面，点绿色按钮 Commit changes


【备用办法：手工创建构建脚本】
如果 .github 这个带点的文件夹拖上去没显示，这样做：

  1. 在仓库页面点  Add file → Create new file
  2. 最上面文件名那一行，完整输入这行字：
         .github/workflows/build-apk.yml
     （前面有个小数点，中间有个斜杠）
  3. 用记事本打开本文件夹里的
         「01-工作流文件_内容.txt」
     全选 → 复制 → 粘贴到网页那个大文本框里
  4. 点右上角绿色 Commit changes


────────────────────────────────────────────
 第 4 步：等着它构建（20～60 分钟）
────────────────────────────────────────────
文件传完就自动开始构建了，不用再点什么。

想看进度：点仓库上方的 Actions 标签页
  黄色圆点 = 正在构建（第一次要下载安卓工具，慢）
  绿色对勾 = 构建成功，可以去下载了
  红色叉   = 失败了，看下面的“常见问题”


────────────────────────────────────────────
 第 5 步：下载 APK，装到手机
────────────────────────────────────────────
变成绿色对勾后：

  1. 点那个任务
  2. 拉到最下面，有个 Artifacts 区，点 tiangongerp-apk
  3. 会下载一个 zip，解压后得到 .apk 文件

把 apk 传到手机（微信 / QQ / 数据线都行），点它安装：

  · 安卓会提示“未知来源 / 未知应用”，选“允许”
    （这是正常的，因为不是从应用商店装的）
  · 装好后桌面会出现天宫图标，打开就是 ERP 界面


===============================================================
 常见问题
===============================================================

Q 手机上打开是空白？
A 本机服务启动要几秒，稍等或关掉重开一次就好。

Q 账号密码是什么？
A 和电脑版完全一样（出厂账号见电脑版 1.0 交付包里的说明）。

Q 手机的数据怎么弄到电脑？
A 手机里进「数据导出」→ 点「生成 CSV」→ 点「复制全部」
  → 微信发到电脑 → 电脑版 ERP 里「批量导入」粘贴进去。
  反过来（电脑 → 手机）也是一样的做法。

Q 手机和电脑的数据会自动同步吗？
A 不会。这是单机版，手机上是一份独立数据。
  需要时用上面的导入 / 导出互倒。

Q 构建失败（红色叉）怎么办？
A 把 Actions 页面里的报错截图，发给帮你做这个包的人。
  多数是小配置问题，改一次就好。

Q 为什么不能直接给我 APK 文件？
A 做安卓安装包必须要用 Linux 环境，你这边是 Windows，
  所以走 GitHub 的免费云端机器来编译，
  这是不用你装任何东西的唯一办法。
